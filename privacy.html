Privacy Policy

Effective date: October 9, 2026
プライバシーポリシー（施行日: 2026年10月9日）

This Privacy Policy explains how Level0 Studio Tools ("the tool") handles information. The tool is used by one person only: the operator of the YouTube channel @level0_, on their own computer, for their own channel. The only user of the tool, and the only person whose data it accesses, is the channel owner. The user agrees to this Privacy Policy before using the tool.

この道具の利用者は、チャンネル @level0_ の運営者1人だけです。扱うデータも、その本人のものだけです。利用者は使う前にこのポリシーに同意します。

1. Use of YouTube API Services

The tool uses YouTube API Services (the YouTube Data API and the YouTube Analytics API). By using the tool, the user agrees to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy (https://policies.google.com/privacy).

この道具は YouTube API サービスを使用しています。YouTube 利用規約と Google プライバシーポリシーをご確認ください。

2. Information the tool accesses and collects

After the channel owner signs in with Google OAuth 2.0, the tool accesses the following data of the owner's own channel only:

  • Channel information, video list, video status, titles, descriptions, thumbnails, captions and playlists of the owner's channel.
  • YouTube Analytics reports of the owner's channel (for example: views, audience retention, traffic sources and search terms).
  • OAuth 2.0 authorization tokens for the owner's own Google account.

The tool does not access data of any other user or channel. It does not collect names, addresses, phone numbers, payment information or contact lists.

持ち主のチャンネルの情報・動画の一覧と状態・題名・概要欄・サムネイル・字幕・再生リスト、持ち主のチャンネルの分析データ、持ち主のアカウントの OAuth の許可情報だけを扱います。他の利用者やチャンネルのデータは扱いません。

3. How the information is used

  • To upload the owner's own videos and schedule their publication.
  • To set thumbnails, update titles, descriptions and chapters, add captions, and manage playlists on the owner's channel.
  • To show the owner the current status of their videos.
  • To help the owner understand their own channel's performance and improve future videos.

The information is not used for advertising, profiling, or any purpose other than operating the owner's own channel.

持ち主の動画の投稿・管理と、自分のチャンネルの分析にだけ使います。広告などの他の目的には使いません。

4. Sharing of information

The tool does not sell, share, or transfer any information to third parties. It has no server of its own: all API requests go directly from the owner's computer to Google's APIs. The tool does not allow third parties to serve content or advertisements.

情報を第三者に販売・共有・提供しません。道具は自前のサーバーを持たず、通信は持ち主の PC から Google の API へ直接行います。第三者による広告などの表示もありません。

許可情報・動画 ID の対応・分析データは持ち主の PC の中にだけ保存します。動画の状態・日付・再生数は保存せず、必要なときに毎回 API から読みます。分析データは少なくとも30日ごとに許可が有効か確かめ、無効なら削除します。

6. Cookies and device storage

The tool does not use cookies or similar tracking technology. This website does not use cookies, analytics or tracking. The tool stores files (the OAuth tokens and the data listed above) only on the owner's own computer.

Cookie や同様の追跡技術は使いません。この Web サイトも Cookie・アクセス解析を使いません。道具は持ち主の PC の中にだけファイルを保存します。

7. Revoking access and deleting data

  • Access can be revoked at any time from the Google security settings page: https://security.google.com/settings/security/permissions (Google Account > Security > Third-party apps & services).
  • The owner can delete all locally stored data at any time by deleting the tool's local files.
  • When access is revoked, the token file and the stored API data are deleted from the owner's computer as soon as possible: within 7 days when revoked in the tool, and within 30 days when revoked through the Google security settings page.
  • Data deletion requests can be sent to the contact email below. They are completed as soon as possible and within 7 calendar days.
  • Deleting data stored by this tool does not affect any data stored by YouTube.

許可は Google アカウントの「サードパーティのアクセス」（上のリンク）からいつでも取り消せます。手元のデータは持ち主が削除できます。データ削除の依頼は下の連絡先で受け付け、7日以内に削除します。この道具のデータを削除しても、YouTube に保存されたデータには影響しません。
